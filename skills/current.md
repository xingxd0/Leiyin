# Expression Extraction Skill v1

Extract English expressions from daily conversations and notes.

Priority:
- Reusable short phrases for work, study, and daily communication.
- Useful single words with clear learning value.
- Expressions that can be reused in future conversations.
- English records for Chinese source content when a reliable translation is available.

Exclude:
- Names, one-off project titles, and private identifiers.
- Very long sentences that are not reusable.
- Generic filler words without learning value.

Candidate format:
- phrase: English word or short phrase.
- meaning: Chinese meaning.
- kind: word or phrase.
- example: Original or translated context sentence.
- count: Occurrence count in the source.
