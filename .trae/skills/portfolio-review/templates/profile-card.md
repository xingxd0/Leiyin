# 操作者内部确认卡片

这张卡片供使用 skill 的操作者确认，不作为候选人交付报告附件。能提取的先填入，来源不明的标为推测或待补充。可交互平台用下拉、单选、多选及短编辑框；否则用以下编号摘要，操作者回复“确认”或只改需要更正的编号。

| 编号 | 字段 | 建议控件 | 值与来源 |
|---|---|---|---|
| 1 | 评审范围 | 项目清单勾选 | 文件、页码/页面，完整或部分可读 |
| 2 | 用途 | 单选 | 求职 / 能力复盘 |
| 3 | 设计相关工作年限 | 数字或区间选择 | 原文信息；未知时不猜；可选未满 1 年、1–3、3–5、5–8、8–10、10+ |
| 4 | 项目场景 | 按项目多选 | B 端 / C 端 / 混合；其他类型标待适配，不硬套模型 |
| 5 | 设计方向 | 多选，可补充 | UI/UX / 平面 / 交互 / 设计系统 / 其他 |
| 6 | 主能力方向 | 单选 | 逻辑与体验 / AI Coding 与实现 / 视觉与表达 |
| 7 | 次能力方向 | 可选 | 仅记录，不在 v0.1 自动混合权重 |
| 8 | 通用评审层级 | 单选 | L1 / L2 / L3 / L4 / L5；职责支持的建议，不代表已达到 |
| 9 | 职责与边界 | 预填短文本 | 主导、参与、协作对象、未负责；缺失可标证据不足 |
| 10 | 职业路线 | 单选 | 专业 IC / 管理 / 尚未明确 |

工作年限区间左闭右开，满 3/5/8/10 年进入下一档。工作年限未知但职责足以确认层级时允许继续；层级也不清楚时不强行给完整评分。

确认操作：**确认以上信息，继续** / **修改指定字段** / **补充材料**。

确认后才进入 JD 步骤：**提供目标岗位 JD** / **跳过，使用通用评审**。不在作者确认前用 JD 重塑作者定位。

需要时在内部记录选择的规则版本、确认状态与依据，不记录不必要的身份信息或联系方式。
